# E-Commerce Sales and Delivery Analysis Using SQL

## Project Overview

This project uses SQL and PostgreSQL to analyze the Olist Brazilian E-Commerce Public Dataset.

The goal is to investigate e-commerce business performance through sales revenue, seller performance, delivery times, customer satisfaction, and monthly revenue trends.

This is an independent portfolio project using public e-commerce data. It does not use Amazon's internal data.

## Tools Used

- PostgreSQL
- pgAdmin 4
- SQL
- GitHub

## Business Questions

1. Which product categories generate the most revenue?
2. Which sellers generate the most revenue?
3. How long do orders take to reach customers?
4. Is late delivery associated with lower customer review scores?
5. How does revenue change month by month?

## SQL Skills Practised

- SELECT, WHERE, and ORDER BY
- Aggregate functions: SUM, AVG, and COUNT
- GROUP BY and CASE
- INNER JOIN and LEFT JOIN
- Date and timestamp calculations
- Data analysis using multiple related tables

## Dataset

**Olist Brazilian E-Commerce Public Dataset**

The dataset contains information about customers, orders, products, sellers, payments, reviews, and deliveries.
